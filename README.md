# Jarvis — персональный AI-ассистент для Windows 11

Jarvis — голосовой AI-ассистент с естественным диалогом, OpenRouter, tool-calling, памятью, Windows-действиями, Telegram, погодой, новостями, криптой и тендерным радаром.

## Что изменено в текущей версии

- Свободная речь идёт напрямую в AI-агент, а не через огромный набор ключевых слов.
- OpenRouter используется через OpenAI-совместимый tool-calling API: модель выбирает инструмент, приложение выполняет его, затем модель формирует ответ. citeturn0search0turn0search1
- Ответы принудительно ориентированы на русский язык.
- Кэш ответов по умолчанию выключен, чтобы динамические данные не становились устаревшими.
- Добавлена SQLite-память.
- Произвольный shell запрещён; локальные действия проходят через отдельные инструменты.
- Добавлен CI: Python 3.11/3.12, компиляция всех `.py` и unit-тесты.
- Голосовой режим переведён на VAD вместо фиксированной записи фразы.
- Добавлен отдельный full-duplex слой TTS: ответ озвучивается в отдельном потоке и может быть прерван новым голосовым вводом.

> Важно: полноценный barge-in работает значительно лучше с наушниками. При использовании колонок микрофон физически слышит голос Джарвиса, и без аппаратного/системного echo cancellation возможны ложные срабатывания.

## 1. Установка Windows 11

Рекомендуется Python 3.11 или 3.12.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -r requirements.txt
```

Для Telegram voice нужен FFmpeg:

```powershell
winget install Gyan.FFmpeg
```

Проверь:

```powershell
ffmpeg -version
```

## 2. Настройка OpenRouter

Создай API key в OpenRouter и положи его только в локальный `.env`.

Скопируй `.env.example` в `.env` и укажи:

```text
OPENROUTER_API_KEY=твой_ключ
JARVIS_MODEL=z-ai/glm-5.3-flash
JARVIS_FALLBACK_MODEL=deepseek/deepseek-v4-flash-0731
```

Не помещай реальный ключ в `config.json` или GitHub.

Текущая схема tool-calling соответствует OpenRouter: приложение передаёт `tools`, получает `tool_calls`, выполняет функции и возвращает результаты модели. citeturn0search0turn0search1

## 3. Проверка

```powershell
python jarvis.py --check
```

Затем текстовый тест:

```powershell
python jarvis.py --text
```

Проверь:

```text
Привет
Что ты умеешь?
Какая погода в Минске?
Открой Google
Создай задачу дописать отчёт
Запомни, что я предпочитаю русский язык
```

## 4. Голосовой режим

```powershell
python jarvis.py
```

Теперь модель не должна ждать заранее заданные команды. Можно говорить нормальными фразами:

- «Джарвис, какая сейчас погода в Минске?»
- «Открой VS Code и потом расскажи, что у меня сегодня по задачам»
- «Найди свежую информацию о биткоине и коротко объясни ситуацию»
- «Добавь задачу закончить лабораторную завтра вечером»

### Диалог и перебивание

Jarvis не должен ждать окончания своей озвучки как единственного способа продолжить диалог. TTS запускается отдельно, микрофон остаётся доступен, а при распознавании новой фразы текущая озвучка останавливается и обрабатывается новая реплика.

Для наилучшего результата используй гарнитуру/наушники. С обычными колонками возможен акустический feedback.

## 5. Telegram

В `.env`:

```text
TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_CHAT_ID=твой_chat_id
```

В `config.json`:

```json
"telegram": {
  "enabled": true,
  "bot_token": "",
  "chat_id": ""
}
```

Переменные окружения имеют приоритет. Если `TELEGRAM_CHAT_ID` не задан, бот может сохранить первый полученный chat id. Для личного использования лучше указать его явно.

## 7. Доступ к компьютеру

Jarvis специально не получает безусловный доступ к произвольному shell. Это плохая архитектура для агента: ошибка модели, prompt injection или случайная фраза может привести к выполнению опасной команды.

Вместо этого доступ расширяется инструментами:

- открытие приложений;
- открытие папок;
- открытие сайтов;
- задачи и напоминания;
- Telegram;
- веб-поиск;
- системная диагностика;
- крипто-мониторинг;
- тендерный мониторинг;
- память.

Следующий уровень для расширения — отдельные разрешённые инструменты файловой системы, браузера и Windows Automation с подтверждением для удаления, отправки, установки программ и других необратимых действий.

## 8. Тесты

Локально:

```powershell
python -m compileall -q .
python -m unittest discover -s tests -v
```

GitHub Actions автоматически запускает эти проверки на Python 3.11 и 3.12.

Важно: CI проверяет программные контракты, импорт, компиляцию и безопасность инструментов. Реальный микрофон, динамики, Windows GUI и физический barge-in нужно дополнительно проверить на твоём Windows-компьютере.

## 9. Архитектура

```text
Микрофон
   ↓
VAD + STT
   ↓
Диалоговый агент
   ↓
OpenRouter / LLM
   ↓
Tool calling
   ├── Windows
   ├── Web
   ├── Память
   ├── Задачи
   ├── Telegram
   ├── Крипта
   └── Тендеры
   ↓
Результат
   ↓
Interruptible TTS
   ↓
Голос пользователя может перебить ответ
```

## Безопасность

- `.env` не должен попадать в Git.
- Не передавай Jarvis произвольный shell без отдельной политики разрешений.
- Данные из веб-поиска считаются внешним недоверенным содержимым.
- Не храни API keys в `profile.md`, `config.json` или исходном коде.
- Для отправки сообщений и необратимых действий используй подтверждение.
