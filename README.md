# 🤖 ДЖАРВИС — персональный AI-ассистент для Windows 11

Голосовой ассистент в стиле Джарвиса Тони Старка: кодовые слова, память сессий,
напоминания, помощь по коду, Telegram-связь с телефоном и ироничный характер.

## ⚡ Установка (Windows 11)

1. Установи Python 3.10+ с python.org (галочка **Add to PATH** — обязательно!)
2. Скачай папку `jarvis` на компьютер
3. Открой PowerShell в папке проекта и выполни:
```powershell
pip install -r requirements.txt
python jarvis.py --check
```
4. Получи бесплатный ключ Gemini: https://aistudio.google.com/apikey
   → вставь его в `config.json` → `brain.api_key`

## 🚀 Запуск

| Команда | Что делает |
|---|---|
| `python jarvis.py` | Голосовой режим (нужен микрофон) |
| `python jarvis.py --text` | Текстовый режим (для теста) |
| `python jarvis.py --check` | Диагностика конфигурации |
| `start.bat` | Запуск двойным кликом |

## 📱 Telegram (управление с телефона)

1. Напиши @BotFather → `/newbot` → получи токен
2. Вставь токен в `config.json` → `telegram.bot_token`, поставь `"enabled": true`
3. Запусти Джарвиса, напиши боту любое сообщение — chat_id сохранится сам
4. Теперь: команды текстом, голосовые сообщения и push-уведомления о напоминаниях

## 🎓 Обучение новым командам голосом

```
Ты:  Запомни команду
ДЖ:  Назовите фразы активации через запятую...
Ты:  включить музыку, музыка
ДЖ:  Фразы записал. Теперь назовите действия...
Ты:  открыть сайт music.youtube.com
ДЖ:  Команда сохранена.
```
Или правь `commands.json` руками — там есть примеры.

## ⚙️ Настройка характера

`config.json` → `brain.sarcasm_level`: 0 (вежливый) … 10 (полный Тони Старк).

## 📦 Сборка в EXE (без Python на целевой машине)

```bat
build_exe.bat
```
Готовый файл появится в `dist\Jarvis.exe`. Запускай двойным кликом.

## 🛠 Если что-то не работает

- **Микрофон**: установи `pip install pipwin && pipwin install pyaudio`
- **Голос**: edge-tts требует интернет; без него включится офлайн pyttsx3
- **Голосовые в Telegram**: нужен ffmpeg в системе (`winget install ffmpeg`)
